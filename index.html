    Enable cross-device sync

    One free Firebase project, about two minutes. Without it the game still works, but only on this device.

    1. Go to console.firebase.google.com and create a project.
    2. Open Build → Realtime Database and create one.
    3. Copy its URL (ends in .firebaseio.com or .firebasedatabase.app) into Settings.
    4. Under Rules, paste this and publish:
    { "rules": { "games": { "$code": { ".read": true, ".write": true } } } }
    These rules let anyone who knows a game code read and write that game. Codes are random and unguessable, and nothing personal is stored — fine for a home game, not for anything sensitive.
